# Recall Relay: use your model, keep the memory

Recall Relay is a bring-your-own-key integration pattern. It checks a user-owned Recall archive before a provider call; on a safe hit it returns the existing asset, and on a miss it calls the provider from the user's device/process and captures the completed bytes back into Recall.

Provider credentials are never sent to Recall or written to B2. For a hosted relay endpoint, use a scoped Recall integration key; for the strongest privacy model, self-host Recall against your own B2 bucket.

## What prompt matching does today

1. **Exact:** normalized prompt equality is always a 1.0 exact match.
2. **Text:** token Jaccard score plus tag overlap catches close wording.
3. **Semantic:** optional Gemini embeddings score paraphrases with cosine similarity. The live threshold for an automatic *recommendation* is 0.70.
4. **Intent Firewall:** even a high semantic score is rejected when brand, campaign, format, license, or language conflicts; missing required profile fields also block reuse.
5. **Human choice:** no result is served automatically. The caller must retrieve, fork, or deliberately generate.

Every assessment produces a Recall Ledger receipt. The raw prompt is retained only in the user's generation record; the receipt contains a salted HMAC commitment instead of repeating it.

## Media matching

Recall stores SHA-256 for every output. `POST /api/v1/capture` deduplicates an externally generated asset when its exact bytes are already archived, avoiding an additional B2 copy. Image captures also compute a 64-bit difference hash for future resized/compressed near-duplicate lookup. Exact output matching saves storage; prompt/semantic matching before provider invocation is what saves model cost.

## Gemini quickstart

```python
from recall_relay import RecallRelay
relay = RecallRelay("https://your-recall.example", recall_key="your scoped Recall key", gemini_key="your Gemini key")
result = relay.generate_gemini(
    "Editorial cobalt glass product image on warm paper",
    tags=["launch", "cobalt"],
    intent={"brand":"Recall", "format":"1:1", "license":"campaign-internal"},
)
print(result.status, result.generation.get("asset_url"))
```

Copy [`../sdk/python/recall_relay.py`](../sdk/python/recall_relay.py) into a project or package it with your own application. On `reused`, no Google request occurred. On `generated_and_captured`, `result.media` holds the just-generated bytes and Recall has archived them for future checks.

## Capture an existing result

For media generated by another workflow, send its base64 bytes to `POST /api/v1/capture`. Recall records this as `external_capture`, not a Genblaze-generated manifest. The resulting byte hash remains verifiable; Genblaze verification continues to apply only to runs Recall orchestrated through Genblaze.
