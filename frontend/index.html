A memory layer, not another folder

A folder waits until after you remember. Recall checks before you pay.

A folder stores files and a DAM organizes them. Recall sits in the generation path, searches shared history across providers, and pauses a paid request when the exact or related work already exists.

01 / PREVENT

Check before the provider call.

Reuse Gate searches shared prompt, intent, tag, model, and semantic history before a model can charge the team again.

02 / RETRIEVE

Return the exact original.

B2 serves the approved bytes. There is no new model call, no changed composition, and no claim that a nondeterministic replay is identical.

03 / FORK

Change one thing on purpose.

Branch from a known-good recipe. The new variation keeps its parent lineage instead of becoming another mystery file.
